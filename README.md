# Мониторинг Maxval

Компактная внутренняя система мониторинга доступности серверов, компьютеров, сетевых
узлов, камер, сайтов и сервисов. Это не аналог Zabbix: проект сохраняет простой
серверный интерфейс и развивается только под подтверждённые практические задачи.

- текущая рабочая версия: `0.8.5`;
- опорный (якорный) релиз: `0.8.5`;
- Alembic head: `0036`;
- дальнейшие планы реализуются только по отдельной команде.

## Возможности

- площадки, недельные графики и ручной порядок площадок/объектов;
- опциональная точка входа площадки: primary DOWN маршрутизатора/сервера временно
  подавляет каскадные проверки объектов площадки;
- Multi-check: одна основная и дополнительные именованные TCP, HTTP, HTTPS, ICMP и
  RTSP-проверки одного объекта; статусы сервисов видны в истории, а управление — в
  редакторе объекта на странице «Объекты»; HTTPS-сервис опционально контролирует срок
  сертификата без изменения доступности;
- SNMP v1/v2c: System/manual OID, безопасные производные формулы, IF-MIB интерфейсы, пороги, Printer-MIB расходники и
  UPS-MIB (RFC 1628 / APC PowerNet) для батареи, питания и нагрузки;
- плановый и ручной опрос, текущие состояния, история, инциденты и отчёты;
- показатели Linux-сервера портала;
- пользователи `admin`/`viewer`, серверные сессии, CSRF, защита входа и аудит;
- SMTP, внутренний центр оповещений, личный чат и PWA Push;
- конфигурационные и полные резервные копии с проверкой целостности;
- адаптивный интерфейс, светлая/тёмная тема и PWA с безопасной offline-заглушкой;
- опциональный HTTPS через Caddy и изолированный TLS-manager.

## Быстрый запуск

Требуются Docker Engine и Docker Compose v2. Релизный ZIP содержит готовый `.env` для
чистой установки. При установке из исходников создайте `.env` из `env.example` и
задайте собственные `POSTGRES_PASSWORD` и `MONITORING_SECRET_KEY`.

```bash
cd /opt/monitoring-maxval
chmod 600 .env
sudo docker compose config >/dev/null
sudo docker compose up -d --build
sudo docker compose ps
curl --fail http://127.0.0.1:8000/health/ready
```

Интерфейс по умолчанию доступен на `http://IP-СЕРВЕРА:8000/`. Чистая установка
создаёт администратора `admin` с паролем `admin`; пароль необходимо сразу изменить.

Необязательные демонстрационные данные:

```bash
sudo docker compose exec app python scripts/seed_demo.py
```

## HTTPS и PWA

HTTP остаётся рабочим режимом по умолчанию. В разделе «Настройки → HTTPS» можно:

- загрузить certificate/private key или создать внутренний CA и TLS-кандидат;
- проверить и активировать candidate;
- независимо включить или выключить HTTPS и redirect HTTP → HTTPS `307`;
- откатиться к последней рабочей TLS-паре;
- настроить предупреждение об окончании сертификата.

HSTS не используется. При истёкшем сертификате или остатке не более двух суток
redirect отключается автоматически, чтобы прямой HTTP оставался доступен.

Установка PWA и Push требуют доверенного HTTPS-контекста. Service worker кэширует
только статические ресурсы и offline-страницу; состояния объектов, инциденты, отчёты,
настройки и API-ответы не используются как актуальные offline-данные.

## Резервные копии и обновление

Перед обновлением создайте и проверьте резервную копию в разделе «Настройки».

- `configuration` содержит конфигурацию без эксплуатационной истории и поддерживается
  только при точном совпадении версии приложения;
- `full` содержит всю базу и восстанавливается только в точно совпадающую версию.

При обновлении существующей установки сохраняйте рабочий `.env`, каталог `tls/` и
Docker volumes. Новый `.env` из ZIP предназначен для чистой установки.

После Git-клонирования создайте локальный `caddy/Caddyfile` из
`caddy/Caddyfile.example`. Рабочий Caddyfile, `.env`, TLS и backup-данные намеренно
не входят в Git.

```bash
cd /opt/monitoring-maxval
sudo docker compose config >/dev/null
sudo docker compose up -d --build
sudo docker compose exec app alembic upgrade head
curl --fail http://127.0.0.1:8000/health/ready
```

Не используйте `docker compose down -v` при обычном обновлении: этот параметр удаляет
постоянные данные.

## Разработка и проверки

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -e '.[dev]'
install -m 600 env.example .env
alembic upgrade head
uvicorn monitoring.main:app --reload
```

```bash
ruff check .
python -m compileall -q src tests tls-manager
python scripts/test_suite.py smoke
python scripts/test_suite.py full
```

Полная регрессия обязательна до сборки и повторно на распакованном релизном ZIP.
Интерфейс дополнительно проверяется вручную на desktop, планшете и телефоне.
