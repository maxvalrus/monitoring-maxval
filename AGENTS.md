# Инструкции для работы с репозиторием

Перед изменением проекта прочитайте полностью:

1. `PROJECT.md` — цели, ограничения и границы;
2. `docs/ARCHITECTURE.md` — текущая архитектура;
3. `docs/ROADMAP.md` — согласованный порядок развития;
4. `docs/DEVELOPMENT.md` — проверки и правила релиза;
5. `docs/TESTING.md` — профили и постоянные правила автоматического тестирования.


Не расширяйте продукт в сторону аналога Zabbix. Новая сложность допустима только под подтверждённую практическую задачу. Любое принятое решение и изменение плана фиксируйте внутри репозитория. Не храните реальные пароли, секреты, адреса и персональные данные.

## Среда разработки

Codex CLI, запущенный из каталога проекта, является разрешённой средой разработки.

В Codex CLI разрешено:
- изучать проект;
- создавать и изменять исходный код;
- изменять документацию;
- запускать тесты;
- выполнять необходимые команды разработки.

Старое правило о выполнении работ только в отдельном чате сборки к Codex CLI не применяется.

## Сборка релизов

Новый релиз собирать только после явной команды пользователя с указанием версии,
например: "собирай 0.7.0".

Без такой команды разрешены разработка, документация, тестирование и подготовительные изменения.

Утверждённые требования и открытые технические решения ветки 0.7.x по HTTPS и PWA
зафиксированы в [`docs/decisions/https-pwa.md`](docs/decisions/https-pwa.md).
