Как настроить проверку

Тип объекта группирует оборудование в интерфейсе, а поле Проверка определяет реальный способ контроля.

  • TCP проверяет подключение к порту: HTTP 80, HTTPS 443, RDP 3389, PostgreSQL 5432, MikroTik WinBox 8291 или фактический порт сервиса.
  • RTSP: выполняет лёгкий запрос к адресу потока на порту 554 без загрузки и декодирования видео. Укажите адрес как 192.168.1.20/stream1 или полный rtsp://… без логина и пароля.
  • HTTP/HTTPS: проверяет ответ веб-сервера; HTTPS дополнительно сообщает срок действия TLS-сертификата.
  • ICMP: проверяет ответ узла без привязки к порту; поле порта скрывается.

Для TCP, HTTP, HTTPS и ICMP укажите IP или DNS без пути. Путь разрешён только для RTSP. Интервал меньше 300 секунд используйте только при необходимости.
