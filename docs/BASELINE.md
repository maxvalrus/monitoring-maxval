# Опорный релиз 0.8.5

## Статус

Версия `0.8.5` является утверждённым опорным (якорным) релизом Monitoring Maxval.
Новый якорь назначается только отдельным решением пользователя.

Якорь фиксирует проверенную архитектуру HTTPS/PWA, Push, резервных копий и тестовых
профилей. Он не требует пересборки старого ZIP.

## Зафиксированная архитектурная база

- HTTP является режимом по умолчанию;
- Caddy обслуживает опциональный HTTPS;
- HTTPS и redirect HTTP → HTTPS `307` включаются независимо и обратимо;
- HSTS не используется;
- TLS-manager работает без Docker socket и применяет только проверенный candidate;
- сертификаты и private keys хранятся вне БД;
- последняя рабочая TLS-пара доступна для rollback;
- PWA использует manifest, иконки, консервативный service worker и offline-страницу
  без устаревших динамических данных.

Полное решение: [`decisions/https-pwa.md`](decisions/https-pwa.md).

## Действующая политика развития

1. Изменения вносятся в текущие исходники, а не копированием старого релизного ZIP.
2. Каждый новый выпуск получает новый номер; опубликованный ZIP не пересобирается под
   другим функциональным содержимым без прямой команды пользователя.
3. Рабочие данные и Docker volumes сохраняются при обычном обновлении.
4. Перед изменением схемы Alembic проверяется на пустой и существующей базе.
5. Конфигурационный и полный импорт требуют точного совпадения версии `0.8.5`.
6. Новый `.env` релизного ZIP используется для чистой установки; рабочий `.env` при
   обновлении не заменяется.
