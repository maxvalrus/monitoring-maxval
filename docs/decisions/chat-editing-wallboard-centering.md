# Редактирование чата и центровка Wallboard

Дата: 2026-09-08

## Решение

- Сообщение внутреннего чата может изменить только его отправитель. Сохраняется
  `edited_at`; отметка «Изменено» показывается для сообщения, которому на момент
  отображения уже исполнилось пять минут. Правка не создаёт отдельное оповещение или
  запись аудита, как и обычная личная переписка.
- Wallboard не меняет сохранённые координаты объектов. Центровка и панорамирование —
  локальные настройки конкретного браузера. При изменении размера окна сдвиг
  ограничивается по фактической области площадки; кнопка центровки возвращает центр
  набора объектов в видимую область.
- Сброс размеров площадок одновременно очищает локальные размеры сетки и выполняет
  центровку объектов. Масштаб конкретной площадки остаётся отдельной настройкой TV.

## Причина

Эти возможности улучшают совместную работу и дежурный экран без изменения мониторинга,
polling, Target Health или серверной схемы расположения площадки.
