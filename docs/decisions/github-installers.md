# Установка и обновление из приватного GitHub

Дата: 2026-09-12. Версия приложения не меняется.

Репозиторий `maxvalrus/monitoring-maxval` является приватным. Для чистой установки
добавлен `scripts/install-from-github.sh`, для штатного обновления Git-клона —
`scripts/update-from-github.sh`. Это не новый механизм релизов и не заменяет
проверенный релизный ZIP: скрипты упрощают установку именно из GitHub-источника.

Оба скрипта требуют Docker Engine с Compose v2, Git, curl и openssl на хосте. Они не
устанавливают Docker автоматически: системная установка Docker должна быть явным
действием владельца сервера.

Для чтения приватного репозитория используется fine-grained GitHub token с единственным
правом `Contents: Read` на этот репозиторий. Токен вводится без отображения, передаётся
Git только через временный `GIT_ASKPASS`, не добавляется в URL remote, `.git/config`,
`.env` или Docker environment и удаляется при завершении скрипта.

Installer создаёт новый `.env` с независимыми случайными секретами, локальный
`caddy/Caddyfile` из versioned example, пустой каталог `tls/`, поднимает Compose,
проверяет readiness и отдельно предлагает загрузить демонстрационные данные. Он
отказывается писать в непустой каталог или использовать уже существующий PostgreSQL
volume: существующую установку нужно обновлять, а не переустанавливать.

Updater сначала по умолчанию создаёт и проверяет PostgreSQL dump, затем требует чистое
состояние отслеживаемых Git-файлов и выполняет только fast-forward update. Он не
заменяет `.env`, `tls/`, backups или Docker volumes и никогда не использует
`docker compose down -v`.
